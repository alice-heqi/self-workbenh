# Analytics Agent 学习工作台

这是依据 `brief.md` 与 `plan.md` 建立的 React + Vite + TypeScript 前端项目。当前只完成 Step 0：项目骨架和模拟数据页面。无需数据库或账号。

## 本地启动

```bash
npm install
npm run dev
```

访问 <http://127.0.0.1:5173/>。

## 验证

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

页面中的学习路线、资料和启动卡都是模拟数据，不会保存。后续步骤再实现资料研究、计划和学习记录。
